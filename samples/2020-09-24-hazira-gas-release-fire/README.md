# Hazira gas terminal release and fire, 24 September 2020

A ProbeMatrix findings export and its Learnings Coach outputs for the hydrocarbon release and fire at the gas terminal of ONGC's Hazira plant in the early hours of 24 September 2020. Nobody was injured.

## Source

**Public source:** PNGRB Enquiry Committee report on the fire at ONGC Hazira Plant, 24 September 2020 (36 pages). The enquiry committee was constituted by the Petroleum and Natural Gas Regulatory Board.

**What the analysis had access to:** a desk analysis of the published enquiry report only. There was no site access, no interviews and no access to ONGC records.

**Sighted analysis:** the committee's own remedial measures (report pages 33 to 36) were part of the evidence pack. Some findings cite those recommendations, so the learnings were not written independently of them; read any comparison with the committee's recommendations as coverage, not independent discovery.

## Outputs

Every file in `outputs/` was drafted by an AI agent with the Learnings Coach from the export above, and none has been reviewed or signed off by a person. Each pack is committed as its JSON (the source), its HTML page (open this first) and its Markdown, written by `pmlc pack`; one pack for each audience and analysis skill, the dossier index `dossier-index` beside `dossier-F02`, the two variants of `report-comparison` and the Hindi variant of `frontline-learning-cards`; the Learnings Register is its own JSON, Markdown and workbook. One file of each other document format is committed as a showcase. The Learnings Register holds 25 learnings and 44 recommendations covering 435 of 436 findings.

The files were rendered with `SOURCE_DATE_EPOCH` set, so they carry a fixed generated date, and `tests/test_hazira_samples.py` (repository only) re-renders each one and compares it with the committed file. To re-render one, build the workspace as below with `--overlay india-process-site`, copy `comparator/*.json` into the workspace, `outputs/nine-m-session.json` into it as `nine_m_session.json` and `outputs/*.json` into the run's `outputs/`, then run `python3 skills/learnings-coach/scripts/pmlc.py pack <workspace> <run>/outputs/<pack>.json` with the flags in the Format column (the two organisation files: `pmlc.py templates <workspace>` with the arguments shown there).

The Hindi pack `frontline-learning-cards-hi` was made through `pmlc strings extract` and `strings apply --lang hi`, with English back-translations of its safety-critical items; it is an AI translation and a fluent speaker checks it before use (each page says so). The toolbox-talk group names ("Returning equipment to service", "Responding to a release") stay in English on the Hindi page, because `group` is a locked field that `strings` does not offer for translation.

## How it was prepared

- The export went through `tools/make-public-sample.py`: only the five sheets the coach reads were kept, and the name scan returned zero hits against a list of every personal name in the enquiry report. `pmlc.py scan-names` over the ProbeMatrix report and `outputs/` also returned zero hits. The ProbeMatrix material names roles only.
- **Summary-sheet corrections:** the date was changed from 2020-08-24 to 2020-09-24 and the incident type from aviation to fire, to match the enquiry report. The ProbeMatrix report was generated before this correction and still shows 2020-08-24 on its cover.
- The guidance printed under each HFACS code in the ProbeMatrix report is the generic code library text, so some lines (for example on aviation brownout landings) are not about this event.
- One finding (FND-44219027) is left out of the register because a reviewer voted to downgrade it.
